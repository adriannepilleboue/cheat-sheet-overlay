# Cheat Sheet Overlay

Toggle a cheat sheet overlay with `Super` + `F2` or by clicking on the indicator. The overlay shows system-wide shortcuts on the left and shortcuts for the focused application on the right. There is no default pinned shortcuts, it's entirely up to the user to add the ones they need, directly from the overlay.

This extension is inspired by [Shortcut GNOME Extension](https://gitlab.com/paddatrapper/shortcuts-gnome-extension), but keeps a per-application list of pinned shortcuts.
